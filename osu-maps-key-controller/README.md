# Osu maps key controller

旨在只用键盘实现谱面集的浏览、试听与控制。

## 脚本匹配网址

即谱面浏览/下载页面

```
https://osu.ppy.sh/beatmapsets**
```

## 使用方法

安装后无需配置，即可使用

## 基本键位

- **Ctrl + ArrowUp**: 上移（按行跳转）。
- **Ctrl + ArrowDown**: 下移（按行跳转）。
- **Ctrl + ArrowLeft**: 左移（上一项）。
- **Ctrl + ArrowRight**: 右移（下一项）。
- **Ctrl + Enter**: 播放当前选中项。
